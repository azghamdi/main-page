# صفحات إحصاءات أسعار العقارات

ارفع محتويات هذا المجلد مباشرة إلى المستودع، بحيث يكون index.html في جذر الموقع.

## الملفات
- index.html: قائمة النشرات.
- publication-brand.css: ألوان النشرات والتفاعلات المشتركة.
- real-estate-price-index-2026-q1-ar.html: الربع الأول 2026.
- real-estate-price-index-2025-q4-ar.html: الربع الرابع 2025.
- real-estate-price-index-2025-q3-ar.html: الربع الثالث 2025.
- .nojekyll: تقديم الملفات كما هي عبر GitHub Pages.

لا تحتاج الملفات إلى تثبيت مكتبات أو عملية بناء. أبقِ HTML وCSS معًا في المجلد نفسه.

لتفعيل العرض: Settings → Pages → Deploy from a branch، ثم اختر فرع الرفع ومجلد /(root)، واضغط Save.

نشرة الربع الثاني 2026 مرتبطة بالرابط الخارجي المحدد:
https://www-dv.stats.gov.sa/ar/w/statistics/repi/2026-q2-1
قد تتطلب هذه الوجهة صلاحية الوصول إلى بيئة التطوير.

الهيدر يحتفظ بروابط الموقع المرجعي، وبعض الصور فيه تُحمّل من نطاقات الهيئة.
